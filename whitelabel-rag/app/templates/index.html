Workflow: Basic RAG

Help

Three steps: upload a document, ask a question, check the sources. Answers come from your files first.

How to use it

  1. Upload a document from the Documents panel — PDF, Word, text, spreadsheets and more. It is indexed automatically.
  2. Ask in Chat. Pick a RAG workflow first if you want a different retrieval style — Basic is the default.
  3. Check the sources listed under each answer. If the answer is not in your documents, the app says so.

RAG workflows

  • Basic RAG — one retrieval, straight answer. Best for most questions.
  • Advanced RAG — expands the question, searches two ways, reranks, adds citations.
  • Recursive RAG — plans the answer, then retrieves per part. Best for multi-part questions.
  • Adaptive RAG — reads the question and picks the strategy itself.

Files you can upload

PDF, Word (.docx), text, Markdown, CSV, web pages (.html), PowerPoint, Excel, ePub, RTF, OpenDocument (.odt) and JSON. Older Office files (.doc, .xls, .ppt) need saving as .docx / .xlsx / .pptx first. A Google Docs link file (.gdoc) is not the document itself — download it as Word or PDF from Google Docs first.

If something goes wrong

  • "Document database service not available" — the document store did not start. Stop the app and start it again; if it keeps happening, another copy of the app may be holding the store folder.
  • "I couldn't find any relevant documents" — upload the document the answer lives in first, then ask again.
  • Slow first answer — the first question after a restart can take a while; later ones are faster.

Where answers come from

Your documents are searched first. The answer is written by Google Gemini, with Groq and Ollama as fallbacks; if no model is reachable, you get the retrieved document text instead of an error. Your files stay on this machine except for the call to the model provider you configured.
